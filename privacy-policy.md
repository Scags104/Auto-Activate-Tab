# Privacy Policy — Auto-Activate New Tabs

**Last updated:** August 2026

Auto-Activate New Tabs does not collect, store, transmit, or share any user data of any kind.

## What the extension does

The extension uses Chrome's `tabs` API solely to detect when a new browser tab is
opened from a link (for example, via middle-click or Ctrl+click) and to switch
focus to that tab automatically. All of this happens locally within your browser.

## Data collection

- No personal data is collected.
- No browsing history, page content, or URLs are read, logged, or stored.
- No data is sent to any server. The extension makes no network requests.
- No analytics, tracking, or advertising code is included.

## Permissions

- **`tabs`** — used only to detect tab-creation events and to activate
  (focus) newly created background tabs. This permission is not used to
  read tab content or browsing history.

## Contact

If you have questions about this privacy policy, please open an issue on
the extension's source repository or contact the developer listed on the
Chrome Web Store listing.
